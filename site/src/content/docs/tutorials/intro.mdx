This tutorial walks through the basic grammar authoring flow in Grammark, from Markdown structure to generated diagrams and tables.

## Create a grammar file

Use a Markdown file with a single H1 and one H2 per nonterminal.

## Add an lr block

Place productions inside a fenced block beginning with `lr`.

## Verify and format

Run the available Grammark tools to validate the file and emit the generated artifacts.
