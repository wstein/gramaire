Gramaire is an LR/IELR(1) parser generator whose grammars **are** Markdown — a
`.gram.md` file renders as normal documentation on GitHub while being the
exact input the generator reads.

This is a placeholder landing page. The full marketing hero, live
source→railroad showcase, and feature tiles (see the gold-standard mock at
[`design/gramark-site-handoff/`](https://github.com/wstein/gramaire/tree/feature/reimplement-site/design/gramark-site-handoff))
land in a later milestone — this page currently exists to verify the design
tokens and Starlight shell render correctly.

See the [brand book](/brand/) for the logomark, wordmark, and color system.
