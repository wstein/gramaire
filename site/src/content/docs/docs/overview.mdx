Gramaire places grammar, documentation, and generated artifacts in one Markdown
document. The [fmt output contract](../../../../docs/fmt-output-contract.md) and
the [IR schema](../specs/ir-schema/) make the grammar both human-readable and
machine-checked. The real implementation is a Scala core, cross-compiled to the
JVM (the `gramaire` CLI) and to Scala.js — the same code either target runs, so
a verdict from one matches the other.

## Where to go next

- **New to Gramaire?** Start with the [tutorial](../../tutorials/intro/) — it
  builds a small calculator grammar from scratch.
- **Want the formal rules?** See the [language specification](../specs/grammar-format/).
- **Looking for a schema or contract artifact?** See the [schema overview](../specs/schema-overview/).
