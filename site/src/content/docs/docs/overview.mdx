Gramark places grammar, documentation, and generated artifacts in one Markdown document. The output contract and the IR schema make the grammar both human-readable and machine-checked, and the Gramark Lab turns that pipeline into an interactive browser-based authoring experience backed by the repository's real PureScript parser.

A grammar is just a set of rules — each names a nonterminal and lists its
productions, the alternatives separated by `|`. Terminals are quoted; a
mixed-case name is another rule. Edit the grammar below and its railroad
diagrams redraw; change the input and the accept/reject verdict follows —
all client-side, on the same engine the CLI ships.

From here, the [tutorial](/gramark/tutorials/intro/) builds a real calculator
grammar step by step, and the [specs](/gramark/specs/schema-overview/) define
the `.grmk.md` envelope and the IR contract every backend reads.
