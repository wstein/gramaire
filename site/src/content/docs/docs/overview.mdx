Gramaire places grammar, documentation, and generated artifacts in one Markdown document. The output contract and the IR schema make the grammar both human-readable and machine-checked, and the Gramaire Lab turns that pipeline into an interactive browser-based authoring experience backed by the repository's real PureScript parser.

Every grammar on this site is live. Edit the source below and the railroad diagrams redraw from the real engine — the same core the `gramaire` CLI runs:
