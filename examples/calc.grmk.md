# Calc

A small arithmetic grammar demonstrating the Gramark fenced envelope.
Operators are left-associative; `*` and `/` bind tighter than `+` and `-`.

## General settings

```gramark settings
%lang javascript
```

## Tokens

```gramark tokens
NUMBER : /[0-9]+/
WS     : /[ \t\r\n]+/   %skip
```

## Expr

An expression is a sum or difference of terms.

```gramark
Expr
  : Expr '+' Term   {% (c) => ({ tag: "Add", left: c.expr, right: c.term }) %}
  | Expr '-' Term   {% (c) => ({ tag: "Sub", left: c.expr, right: c.term }) %}
  | Term
```

![Railroad diagram for the Expr rule](diagrams/calc/expr.svg)

## Term

A term is a product or quotient of factors.

```gramark
Term
  : Term '*' Factor {% (c) => ({ tag: "Mul", left: c.term, right: c.factor }) %}
  | Term '/' Factor {% (c) => ({ tag: "Div", left: c.term, right: c.factor }) %}
  | Factor
```

![Railroad diagram for the Term rule](diagrams/calc/term.svg)

## Factor

A factor is a number or a parenthesised expression.

```gramark
Factor
  : '(' Expr ')'    {% (c) => c.expr %}
  | NUMBER          {% (c) => ({ tag: "Lit", value: Number(c.number) }) %}
```

![Railroad diagram for the Factor rule](diagrams/calc/factor.svg)

## Precedence

Earlier declarations bind more loosely than later ones.

```gramark precedence
%left '+' '-'
%left '*' '/'
```
