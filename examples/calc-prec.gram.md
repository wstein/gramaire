# Calc (precedence)

The calculator grammar in its **natural ambiguous form** — `expr op expr` for
every operator, not stratified into `expr` → `term` → `factor` — with
associativity and binding strength declared in `## Precedence` instead of baked
into the rule shape (ADR D37). The `%left` declarations resolve the shift/reduce
conflicts the ambiguity creates; an operator left _undeclared_ would still be a
build error, so precedence convenience never hides a real ambiguity.

Compare [`calc`](calc.gram.md), which encodes the same language by
stratification and needs no precedence block.

## expr

```grammark
expr
  : expr '+' expr   # Add   {% \l _ r -> Add l r %}
  | expr '-' expr   # Sub   {% \l _ r -> Sub l r %}
  | expr '*' expr   # Mul   {% \l _ r -> Mul l r %}
  | expr '/' expr   # Div   {% \l _ r -> Div l r %}
  | '(' expr ')'    # Paren {% \_ e _ -> e %}
  | NUM             # Lit   {% \n -> Lit n %}
```

## Precedence

```grammark precedence
%left '+' '-'
%left '*' '/'
```
